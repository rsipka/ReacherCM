Reacher CM

A free, open source SSH client and connection manager. Terminals, remote desktops, file transfer, tunnels and an encrypted vault in one app, with no account and no subscription.

Added in Reacher CM

Import from Remote Desktop Manager

RDP, SSH, VNC and Telnet entries, folders, logins, notes and custom fields from an RDM export.

Saved credentials

One login kept once in a vault and used by many sessions, a whole folder or a jump host.

Password managers

Use logins straight from Passbolt, 1Password, Bitwarden or KeePass.

Local-first sync

Every vault works offline and syncs in the background through Turso, a folder, SFTP, Git, an SMB share or an S3 bucket.

Session notes and fields

Free-text notes and named fields on each session, encrypted and synced.

Telnet sessions

For switches, routers and console servers, with automatic login.

Broadcast input

Type or paste into several terminals at once.

Searchable session history

Optionally keep commands and output in an encrypted, searchable history, with secrets masked.

Terminal colors

Hundreds of color schemes, per-session colors and your own editable themes.

Everything from Reach

  • SSH with tabs, split panes and tab groups, and full ~/.ssh/config support (ProxyJump, ControlMaster, FIDO2 keys and more).
  • Remote Desktop (RDP) and VNC in a tab, local shells, WSL and serial consoles.
  • SFTP file explorer with drag and drop and in-place editing.
  • Port tunnels, snippets, system monitoring, Ansible and OpenTofu.
  • An encrypted vault for sessions and secrets, with strict host key checking.
  • Native Rust networking and a fast UI. No Electron.

Install on Linux with apt or dnf

Add the signed repository once, and your system's own updates keep Reacher CM up to date. It follows stable releases; dev builds are on the releases page only.

Ubuntu, Debian and derivatives

sudo apt install -y curl gpg
curl -fsSL https://github.com/rsipka/ReacherCM/releases/latest/download/reachercm-packages.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/reachercm.gpg
echo "deb [signed-by=/usr/share/keyrings/reachercm.gpg] https://github.com/rsipka/ReacherCM/releases/latest/download ./" \
  | sudo tee /etc/apt/sources.list.d/reachercm.list
sudo apt update && sudo apt install reacher-cm

Fedora, RHEL and derivatives

sudo tee /etc/yum.repos.d/reachercm.repo <<'EOF'
[reachercm]
name=Reacher CM
baseurl=https://rsipka.github.io/ReacherCM/rpm
enabled=1
repo_gpgcheck=1
gpgcheck=0
gpgkey=https://rsipka.github.io/ReacherCM/reachercm-packages.asc
EOF
sudo dnf install reacher-cm

The key is trusted for this repository only. Every index is signed with it, and each package is checked against the checksum in the signed index.

Credits

Reacher CM is a personal fork of Reach by Alexander Nt. and the Reach contributors. Almost everything here is their work. Some features are based on the ReachQ fork by CPTProgrammer. If you do not need what Reacher CM adds, use Reach itself.

Most of the code Reacher CM adds is written with AI coding tools, then reviewed and tested by the maintainer. Reacher CM installs next to Reach with its own data folder, so both can be used side by side.
